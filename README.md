# Reynaldo Monzón Studio

Sitio web local de portafolio artístico para `reynaldomonzonstudio.com`.

## Ver localmente

Desde esta carpeta, ejecutar:

```powershell
node server.js
```

Abrir `http://localhost:8080` en el navegador.

No requiere instalación de paquetes ni conexión a una base de datos.

## Sitio publicado

- Dominio: `https://reynaldomonzonstudio.com`
- GitHub Pages: `https://jesusmfb07.github.io/reynaldo-monzon-studio/`
